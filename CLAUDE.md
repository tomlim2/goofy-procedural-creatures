# CLAUDE.md

The working rules for this repo live in [`guidelines/README.md`](guidelines/README.md).

**Read `guidelines/README.md` before starting any work.** The two axes — character (form) and motion
(movement) — the catalog and rules documents, the determinism (seed) rules and the check scripts are all
there. If you are changing a part, read [`guidelines/character/rules.md`](guidelines/character/rules.md)
first; if you are changing motion, read [`guidelines/motion/rules.md`](guidelines/motion/rules.md) first.

When the rules themselves change, edit the documents under `guidelines/`, not this file.
